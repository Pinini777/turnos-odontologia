# Mockups HTML — `C-14 web-paciente`

Mockups responsive (`390×844` y `1440×900`) basados en `design-system/tokens.css` (revisión 2, **Clínica Dental Alvear**), 100 % datos ficticios (`RN-DA-01`), terminología **box** y sin precios (`RN-RO-01`):

1. `disponibilidad.html` — Selección de prestación reservable online, fecha, profesional opcional, huecos libres agrupados por Mañana y Tarde, resumen de reserva y estado de conflicto `409 SOLAPAMIENTO_PROFESIONAL` ofreciendo elegir otro horario.
2. `confirmacion.html` — Confirmación de turno con bloque de fecha calendario, datos de Clínica Dental Alvear, botón **Agregar a Google Calendar** y **Descargar .ics**.
3. `mis-turnos.html` — Listado "Mis turnos" con aviso de política de 24 horas, acciones habilitadas para turnos fuera de las 24 h y un turno dentro de las 24 h con **Reprogramar** y **Cancelar turno** deshabilitados por plazo vencido.
