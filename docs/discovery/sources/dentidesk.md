# Dentidesk

- **URL**: https://www.dentidesk.com/
- **Fecha de investigación**: 2026-11-21

## Problema que resuelve

Administrar la clínica dental de forma sencilla, rápida y segura, con fichas clínicas digitales y agendamiento.

## Usuarios objetivo

Clínicas dentales; versiones para centros médicos y hospitales, instituciones educativas (facultades de odontología) y sindicatos.

## Features detectadas

- Agenda de citas personalizable (agendar, modificar, reprogramar, notas, recordatorios).
- Historial médico y fichas de especialidad: ortodoncia, cirugía ortognática, periodoncia, interconsultas, derivaciones.
- Insumos y stock; más de 20 tipos de reportes financieros y administrativos; facturación; gestión multisucursal.
- Firma digital de consentimientos informados; integraciones (sin detalle).
